## 🔧 Technical Stack

- **Framework**: Nuxt 3
- **UI**: Vue 3 + Tailwind CSS
- **State Management**: Pinia
- **Database**: Firebase Firestore
- **AI**: OpenAI API
- **Icons**: Lucide Vue

## 🧩 Reusable Components

### UI Components:
- **UiModal** - Reusable modal component with Teleport and transitions
- **UiGradientButton** - Primary action button with gradient styling
- **Stat Cards** - Metric display cards with icons and growth indicators
